# اختبارات محرك الاستيراد

هذه المجموعة تمنع تراجع دقة محرك التعرّف عند إضافة قواعد جديدة.

## قواعد الأولوية المعتمدة

1. أي سطر يبدأ بـ `داخلي` أو `خارجي` أو `داخلي/خارجي` (ومنها `داخلي خارجي`) يعد عنوان مشهد جديداً.
2. الصيغة `المشهد + الرقم + داخلي/خارجي/داخلي خارجي` تعد مشهداً جديداً، مع دعم `المشهد رقم 3` أيضاً.
3. النص المكتوب بين قوسين يصنف `حالة` قبل أي تخمين سياقي.
4. السطر الانتقالي الذي يبدأ بـ `قطع`، بما فيه `قطع إلى` و`قطع...`، يصنف انتقالاً. إذا لم يكن السطر الموالي عنوان مشهد صريحاً، ينشئ المحرك بداية مشهد جديدة فارغة ليكمل الكاتب Metadata في المعاينة.
5. بعد هذه القواعد الصريحة فقط يبدأ التحليل السياقي للشخصية والحوار والوصف والفعل.

> ملاحظة: لا تعامل كلمة `قطع` داخل جملة عادية مثل `قطع أثواب` كانتقال؛ المقصود هو علامة الانتقال في أول السطر.

## العينات الحالية

- `episode-reference-01.md`: عينة سيناريو حقيقية طويلة، وهي المرجع الأول لعدم تراجع التعرف على الحلقة الواقعية.
- `priority-rules-ar.txt`: عينة صغيرة مخصصة لاختبار قواعد الأولوية نفسها.
- `word-like-compact-ar.txt`: عينة تحاكي Word حين تأتي عناصر السيناريو كفقرات متتابعة من دون أسطر فارغة، للتأكد من فصل الشخصية عن الوصف والحوار.

عند توفر نماذج حقيقية جديدة، تضاف إلى `fixtures` مع توقعات صريحة في `run.cjs`. الهدف لاحقاً هو وجود عينات مرجعية مستقلة لكل تنسيق يدعمه الاستيراد، لا اختبار أمثلة مصطنعة فقط.
