# Scene Writer v0.6.13

محرر سيناريو عربي مكتبي مبني بـ Svelte + Tauri، مع إدارة مشاريع ومواسم وحلقات ومشاهد، ملف مشروع، استيراد قابل للتصحيح، ومساعد تحليلي خوارزمي محلي.

## الجديد في 0.6.13 — تبسيط الهيكل وتصحيح اكتشاف الشخصيات

- إزالة قائمة المشاهد من «هيكل المشروع» في المسلسل؛ الشريط الأيمن يعرض ملف المشروع والمواسم والحلقات فقط، بينما تبقى المشاهد في لوحة المشاهد اليسرى.
- تغيير عداد «المواسم والحلقات» ليعرض عدد الحلقات بدل عدد المشاهد، مع بقاء عدد مشاهد كل حلقة بجانبها.
- نقل أمر «نقل المشهد إلى حلقة أخرى» إلى بطاقة المشهد في لوحة المشاهد حتى لا نفقد الوظيفة بعد إزالة تكرار المشاهد من الشجرة اليمنى.
- إعادة بناء قائمة الشخصيات المستخرجة من النص بصورة محافظة: الاسم لا يظهر كمقترح جديد إلا إذا كان Block شخصية، وكان شكله شبيهاً باسم متكلم، وتبعه حوار مباشرة أو حالة ثم حوار.
- استبعاد الشخصيات الموجودة أصلاً في ملف المشروع من قسم المكتشفات، واستبعاد العبارات الحركية والحوارية العامة مثل «يتراجع» و«يساعده على النزول» و«وفين هاد الحبة».
- إعادة تسمية القسم إلى «شخصيات جديدة مكتشفة»؛ الإضافة إلى ملف الشخصيات تبقى بقرار الكاتب.
- فهرس الشخصيات المشتق يعاد حسابه من جميع الحلقات من دون تعديل نص السيناريو المحفوظ.

## التشغيل محلياً

يفترض أن يكون جذر المشروع على Windows:

```text
C:\SceneWriter
```

ثم:

```powershell
cd C:\SceneWriter
npm install
npm run tauri dev
```

## مبدأ المشروع

Scene Writer أداة للكاتب: تنظّم، تقيس، وتنبّه. لا تحاول أن تحل محل الكتابة الإبداعية، ولا تعتمد على ذكاء اصطناعي خارجي أو خدمة خلفية إلزامية.

## وضع المساعد المنقسم في v0.7.2

عند استدعاء المساعد لا يغطي نص السيناريو. تتحول مساحة العمل مؤقتاً إلى جزأين: المساعد التحليلي في جانب، وصفحة السيناريو في الجانب الآخر قابلة للقراءة والتحرير. يمكن سحب الفاصل بين الجزأين لتغيير المساحة، ويُحفظ العرض المفضل محلياً. النقر على مشهد أو ملاحظة في المساعد ينقل صفحة السيناريو إلى موضعها، وتُبرز المداخلة نفسها عندما تكون الملاحظة مرتبطة بكتلة حوار محددة. عند إغلاق المساعد تعود الواجهة الأصلية.

## المساعد التحليلي في v0.7.1
يحافظ المساعد على التحليل البنيوي السابق، ويضيف أسماء بديلة للشخصيات وبصمة حوار وصفية ومقارنة تركيب المشهد بوسيط الحلقة/العمل، من دون تقييم أدبي أو كتابة بديلة عن الكاتب.
