# LE CINEASTE — Scene Writer v0.7.2

مستودع التطبيق الحالي **Scene Writer**، محرر سيناريو عربي مكتبي مبني بـ Svelte + Tauri.

## الحالة المرجعية الحالية

الإصدار المختبر في نهاية جلسة 2026-08-14 هو **v0.7.2**.

أبرز ما استقر حتى هذه النقطة:
- محرر سيناريو عربي منظم بعناصر: وصف، فعل، شخصية، حالة، حوار، توجيه، انتقال.
- صفحة حلقة/سيناريو متصلة مع بقاء المشاهد وحدات مستقلة داخليًا.
- إدارة مسلسل: موسم ← حلقة ← مشهد.
- استيراد باللصق وDOCX وFountain مع التعرف والمعاينة والتصحيح قبل الإدخال.
- مساعد تحليلي خوارزمي محلي يقيس ويقارن ولا يكتب بدل الكاتب.
- في v0.7.2 يعمل المساعد في **وضع منقسم** إلى جانب نص السيناريو، ويعود التطبيق إلى وضعه الأصلي عند إغلاقه.

## مبدأ المشروع

Scene Writer يساعد الكاتب على التنظيم والقياس والمراجعة، ولا يحل محل الكتابة الإبداعية ولا يعتمد على خدمة ذكاء اصطناعي خارجية إلزامية.

## التشغيل المحلي

جذر التطبيق على Windows:

```text
C:\SceneWriter
```

ثم:

```powershell
cd C:\SceneWriter
npm install
npm run tauri dev
```

> ملاحظة: هذا المستودع أُنشئ ليكون المستودع الجديد المستقل للتطبيق الحالي، بعيدًا عن مستودعات التجارب السابقة.
